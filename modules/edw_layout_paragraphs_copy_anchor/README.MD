# EDW Layout Paragraphs Copy Anchor
 This module assigns paragraph IDs as div element IDs using the format ``content-paragraph-id``. \
 A new button is added on the layout builder controls that copies in the clipboard the paragraph anchor.
 
## Notes:
 _The button will appear only on paragraphs that have neen created in the database and have an ID_. \
 Save the content to create the paragraphs and then 'the copy anchor' button will appear.

## Usage
 You can use this function to create anchor links to content of the current page using CKEditor or to create submenus with the page sections.
